Cara Penggunaan (Tutorial & API)

Integrasikan aplikasi eksternal atau Database Anda sendiri ke dalam WAGW PRO.

1. Pengiriman Via Tabel Database (Auto-Loop)

Anda bebas menggunakan DBMS apa saja (MDB, MySQL, SQL Server) asalkan terkoneksi di tab Config. Cukup masukkan perintah INSERT ke tabel outbox!

INSERT INTO outbox (wa_no, wa_text) VALUES ('62812xxx', 'Ini Pesan Uji Coba');

2. Pengiriman Via API (CURL / HTTP Post)

Jika Anda mempunyai App Web (PHP, Laravel, atau Webhook), cukup tebak endpoint API ini, langsung masuk ke antrean!

URL: http://localhost:3000/api/send
METHOD: POST
CONTENT-TYPE: application/json
JSON BODY:
{
  "no": "62812xxxxx",
  "text": "Pesan tagihan Anda..."
}

3. Mengirim Pesan Ke Dalam Grup WhatsApp

WAGW PRO mendukung pengiriman terarah ke dalam sebuah Grup secara native. Cukup gunakan Group ID ditambah akhiran @g.us di kolom target nomor.

12036304899999999@g.us
*Gunakan fitur Group Fetcher di tab Tools untuk mengekstrak ID Grup yang Anda ikuti.

3. Format Interactive & Polling Media

Trik rahasia Baileys: Ketik format ini ke dalam kolom wa_text untuk dikirim sebagai pesan menakjubkan:

  • Kirim Polling: POLLVOTE!Siapa Presiden RI?~Joko Widodo~Gus Dur~BJ Habibie
  • Kirim Tombol (Reply/Url/Copy):
    TEXTWITHBUTTON!Silakan kunjungi web~{"buttonId": "id1", "buttonText": {"displayText": "Buka Situs"}, "type": 1}
  • Kirim Gambar + Teks (API): Sertakan Body tambahan "media": "data:image/jpeg;base64,..." pada HTTP Request, atau pada kolom wa_media.
