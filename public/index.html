Kirim WhatsApp dari JIBAS

Gunakan menu SMS JIBAS seperti biasa. JIBAS WG menggantikan pengiriman SMS keluar, bukan aplikasi JIBAS.

  1. Hentikan consumer SMS lama. Pada halaman Status, pastikan worker JIBAS siap dan MOVE aktif.
  2. Tautkan akun WhatsApp melalui QR jika diperlukan.
  3. Buat pesan teks dari menu SMS JIBAS. Gunakan satu nomor yang disetujui untuk uji pertama.
  4. Pantau Outbox dan Sent. Status sent bukan bukti pesan diterima atau dibaca.

Jalur pesan: jbssms.outbox → worker JIBAS WG → antrean gateway → WhatsApp. Pesan terjadwal menunggu waktu pengiriman.

Menu Uji WhatsApp hanya memeriksa pengiriman langsung; hasilnya tidak membuktikan perpindahan antrean JIBAS. Lihat README proyek untuk perintah instalasi dan cutover.
