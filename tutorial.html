Pengiriman SMS JIBAS melalui WhatsApp

Gunakan JIBAS yang sudah terpasang. JIBAS WG membutuhkan MySQL/MariaDB dengan schema jbssms dan jibas_wg pada instance yang sama. Saat upgrade, pertahankan schema yang digunakan instalasi lama.

  1. Cadangkan database dan hentikan consumer SMS lama. Periksa antrean lama sebelum mengaktifkan MOVE.
  2. Ikuti README untuk perintah pemasangan Windows atau Ubuntu/Debian. Instalasi normal selalu memasang integrasi JIBAS.
  3. Buka dashboard, pastikan worker JIBAS siap dan MOVE aktif, lalu tautkan WhatsApp melalui QR.
  4. Kirim pesan teks dari menu SMS JIBAS. Periksa Outbox, Sent, dan status bridge; konfirmasikan penerimaan pada ponsel tujuan.

Mode staging --no-activate-move tetap memasang trigger tetapi menjeda transfer. Tidak ada replay antrean lama otomatis. Uji langsung di dashboard bukan pengujian jalur JIBAS.
