PANDUAN LENGKAP WAGW PRO

Bot WhatsApp/Gateway yang dapat dikontrol melalui Database SQL dan Dashboard Web secara *Real-Time*, yang sanggup berjalan mandiri tanpa henti (*Background Service*).

1. Persiapan Database (MySQL, Oracle, atau SQL Server)

Sebelum menjalankan Bot, pastikan struktur database Anda sudah di-*import*. Parameter tabel (*inbox, outbox, sent*) adalah nyawa utama jalannya program ini.

Gunakan SQL Dump yang telah disediakan sesuai dengan mesin Database Anda:

  • Create Tables - MySQL.sql
  • Create Tables - Oracle.sql
  • Create Tables - SQLServer.sql

2. Konfigurasi BOT Kredensial

WAGW PRO membaca semua setting koneksinya. Anda dapat mengatur Password Database, Jenis DB (mysql/oracle/sqlserver), hingga kecepatan pengiriman pesan (*Send Delay*) semuanya langsung dari tampilan Website WAGW PRO Dashboard.

Penting: Jika Anda salah memasukkan Kredensial Database, WAGW PRO akan memunculkan tulisan "Disconnected / Checking" di Layar Web-nya. Anda cukup pindah ke tab Config, perbaiki Password/Username DB Anda sesuai lokal PC Anda, klik Save, lalu Restart aplikasi.

3. Cara Menjalankan Aplikasi (Pilih Salah Satu)

CARA 1: Otomatis di Latar Belakang (Jalan Terus Selamanya) [Disarankan]

Membuat bot Anda menjadi Windows System Service murni (Otomatis nyala setelah komputer Reboot tanpa layar hitam).

  • Jalankan Install_to_Windows_Service.bat (Klik dua kali).
  • Jika muncul notifikasi Windows (*User Account Control*), klik Yes.
  • Bila sukses di-*install*, Anda sudah tidak membutuhkan Terminal / CMD lagi. (Catatan: Gunakan Uninstall_Windows_Service.bat jika suatu hari ingin menghapus secara permanen).

CARA 2: Semi-Latar Belakang Ringan

Menjalankan secara *invisible* sementara saat ini (hanya terhubung selama komputer belum dimatikan).

  • Klik ganda pada START.bat
  • Layar terminal akan disembunyikan menggunakan PowerShell dan Browser Web otomatis terbuka.
  • Untuk mematikannya kapan saja, Anda harus nge-klik rutin STOP.bat.

4. Tautkan WhatsApp & Dashboard Web

Setelah WAGW PRO dijalankan, silakan buka Browser Chrome/Edge lalu pergi ke:

http://localhost:3000

Bila koneksi berhasil tersambung, QR Code akan muncul jelas di Layar Anda.
Buka Aplikasi WhatsApp Anda di HP → Linked Devices (Tautkan Perangkat) → Scan Layaknya WhatsApp Web.

5. Cara Mengirim Pesan (Outbox SQL & API)

WAGW PRO mendukung dua metode pengiriman pesan: Melakukan Insert data ke Database (Tabel Outbox) ATAU dengan memanggil instruksi REST API.

A. Metode Insert Tabel Outbox SQL

Sangat cocok jika dikendalikan dari *Backend Server* anda (PHP/Java/Python).

1. Pesan Teks: 
INSERT INTO outbox (wa_no, wa_text) VALUES ('628123456789', 'Halo, dari SQL!');
2. Kirim Gambar dengan Caption:
Logika: Jika tabel outbox di kolom wa_media terisi path lokal gambar, maka diproses sebagai Kirim Gambar. Parameter wa_text menjadi Caption.
INSERT INTO outbox (wa_no, wa_text, wa_media) VALUES ('628123456789', 'Foto produk', 'C:\\images\\produk1.jpg');
3. Kirim File/Dokumen (PDF, DOCX):
Logika: Jika tabel outbox di kolom wa_file terisi path, maka diproses sebagai Kirim Dokumen File.
INSERT INTO outbox (wa_no, wa_text, wa_file) VALUES ('628123456789', 'Berikut lampiran', 'C:\\docs\\invoice_01.pdf');
4. Kirim Tombol (Button): 
INSERT INTO outbox (wa_no, wa_text) VALUES ('628123456789', 'TEXTWITHBUTTON! Pilih Opsi|Kunjungi Web|http://web.com|Beli|http://beli.com');
5. Kirim Polling (Poll): 
INSERT INTO outbox (wa_no, wa_text) VALUES ('628123456789', 'POLLVOTE! Apa buah favorit Anda?:Apel:Mangga:Jeruk');

B. Metode Kirim Melalui REST API JSON

Anda bisa men-Hit URL http://localhost:3000/api/send dengan Method POST menggunakan Body berupa format JSON.

Payload Lengkap Kirim Media dan File: 
{
    "no": "628123456789",
    "text": "Halo, ini pesan via API!",
    "media": "C:\\images\\produk1.jpg",
    "file": "C:\\docs\\invoice.pdf"
}
*Kosongkan saja key "media" atau "file" jika hanya ingin mengirim Text biasa.
Info: API Send ini berfungsi mendaftarkan JSON di atas menjadi baris baru pada antrean tabel `outbox`. WAGW PRO akan secara otomatis menghisapnya untuk dikirim menurut sistem antrean *Delay*!

6. Integrasi Pesan Masuk (Webhook & Inbox)

WAGW PRO akan merekam semua riwayat chat masuk (Nomor pengirim, Pesan Text, Waktu) langsung ke tabel database inbox. Anda bisa memeriksanya berkala.

Selain database, Anda juga dapat membajak pesan masuk yang diterima bot tersebut secara Live (Waktu Nyata) menuju link Webhook di HTTP Server milik Anda sendiri.

  1. Isi URL Webhook milik Anda di tab Config Dashboard Web (Contoh: http://domain.com/webhook.php)
  2. Sistem WAGW PRO akan melakukan POST Request dengan parameter: wa_no, text, dan isMedia setiap kali ada lawan bicara yang mengirim WA.
  3. Cek file webhook.php terlampir di folder aplikasi ini untuk mempelajari baris kodenya (mencakup contoh fitur `Balasan Otomatis`).
